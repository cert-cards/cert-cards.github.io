# 빅데이터 결과 해석 (분석모형 평가 및 개선)

> 4과목 앞부분. 출제기준(2024.1.1~2026.12.31)의 주요항목 분석모형 평가 및 개선을 다룬다. 분석결과 해석 및 활용은 04b 파일에 있다. 분류 지표 계산 카드는 같은 혼동행렬(TP 40, FP 10, FN 20, TN 130, 전체 200)을 쓴다.

## 분석모형 평가 › 평가 지표 (분류)

- **혼동행렬 (Confusion Matrix)** — 실제 클래스와 예측 클래스의 조합별 건수를 TP, FP, FN, TN 네 칸으로 정리한 표
- Q: FP와 FN의 뜻 — FP는 실제 음성을 양성으로 잘못 예측한 것(1종 오류), FN은 실제 양성을 음성으로 잘못 예측한 것(2종 오류)
- **정확도 (Accuracy)** — 전체 중 맞게 예측한 비율, (TP+TN)/전체
- **정밀도 (Precision)** — 양성으로 예측한 것 중 실제 양성의 비율, TP/(TP+FP)
- **재현율 (Recall)** — 실제 양성 중 양성으로 맞힌 비율, TP/(TP+FN). 민감도, 참 양성률과 같다
- **특이도 (Specificity)** — 실제 음성 중 음성으로 맞힌 비율, TN/(TN+FP)
- **F1 점수 (F1 Score)** — 정밀도와 재현율의 조화평균, 2PR/(P+R)
- Q: TP 40, FP 10, FN 20, TN 130일 때 정확도 — `0.85`
  - 검산: `(40 + 130) / 200` = 0.85
- Q: TP 40, FP 10, FN 20, TN 130일 때 정밀도 — `0.8`
  - 검산: `40 / (40 + 10)` = 0.8
- Q: TP 40, FP 10, FN 20, TN 130일 때 재현율(소수 셋째 자리) — `0.667`
  - 검산: `40 / (40 + 20)` = 0.667
- Q: TP 40, FP 10, FN 20, TN 130일 때 특이도(소수 셋째 자리) — `0.929`
  - 검산: `130 / (130 + 10)` = 0.929
- Q: TP 40, FP 10, FN 20, TN 130일 때 F1 점수(소수 셋째 자리) — `0.727`
  - 검산: `2 * 0.8 * (40 / 60) / (0.8 + 40 / 60)` = 0.727
  - 2TP/(2TP+FP+FN) = 80/110으로 구해도 같다
- Q: TP 40, FP 10, FN 20, TN 130일 때 거짓 양성률(소수 셋째 자리) — `0.071`
  - 검산: `10 / (10 + 130)` = 0.071
- **카파 통계량 (Cohen's Kappa)** — 우연히 맞을 확률을 걷어 내고 본 예측과 실제의 일치도. 1이면 완전 일치, 0이면 우연 수준이다
- Q: TP 40, FP 10, FN 20, TN 130일 때 카파 통계량 — `0.625`
  - 검산: `(0.85 - (50 / 200 * 60 / 200 + 150 / 200 * 140 / 200)) / (1 - (50 / 200 * 60 / 200 + 150 / 200 * 140 / 200))` = 0.625
  - 우연 일치 확률은 0.075 + 0.525 = 0.6이다
- Q: 암 진단처럼 환자를 놓치면 큰일 나는 경우 중시하는 지표 — 재현율 (FN을 줄여야 한다)
- Q: 스팸 필터처럼 정상 메일을 막으면 곤란한 경우 중시하는 지표 — 정밀도 (FP를 줄여야 한다)
- Q: 양성이 1%뿐인 데이터에서 전부 음성으로 예측한 모형의 정확도와 문제점 — 정확도 99%지만 양성을 하나도 못 잡는다. 불균형 데이터에서는 정확도만 보면 안 된다
- Q: 분류 임계값을 높일 때 정밀도와 재현율의 일반적인 변화 — 정밀도는 오르고 재현율은 내려간다
- **F-베타 점수 (F-beta Score)** — 재현율에 정밀도보다 β배 비중을 두는 조화평균. β가 1보다 크면 재현율, 작으면 정밀도를 중시한다
- **ROC 곡선 (Receiver Operating Characteristic Curve)** — 분류 임계값을 바꿔 가며 x축에 거짓 양성률, y축에 참 양성률을 찍어 이은 곡선
- **AUC (Area Under the Curve)** — ROC 곡선 아래 면적. 1에 가까울수록 좋고 0.5는 무작위 수준이다
- Q: ROC 곡선에서 완벽한 분류기가 지나는 점 — 왼쪽 위 (거짓 양성률 0, 참 양성률 1)
- Q: AUC를 확률로 해석하면 — 무작위로 고른 양성 하나의 점수가 무작위로 고른 음성 하나의 점수보다 높을 확률
- Q: 양성이 매우 드문 데이터에서 ROC 곡선과 함께 보는 곡선 — 정밀도-재현율(PR) 곡선
- **이익 도표 (Gain Chart)** — 예측 확률 순으로 정렬한 데이터를 구간(예: 10분위)으로 나눠 실제 양성이 누적으로 얼마나 잡히는지 보여주는 도표
- **향상도 곡선 (Lift Curve)** — 분위별 반응률을 전체 반응률로 나눈 값을 그린 곡선. 상위 분위에서 높고 빠르게 떨어질수록 좋은 모형이다
- Q: 전체 반응률 5%, 모형 상위 10% 고객의 반응률 20%일 때 그 분위의 향상도 — `4`
  - 검산: `0.20 / 0.05` = 4

## 분석모형 평가 › 평가 지표 (회귀)

> 계산 카드는 실제값 10, 20, 30과 예측값 12, 18, 33을 쓴다. 오차는 2, -2, 3이다.

- **MAE (Mean Absolute Error)** — 오차 절댓값의 평균. 큰 오차에 덜 민감하다
- **MSE (Mean Squared Error)** — 오차 제곱의 평균. 큰 오차에 큰 벌점을 준다
- **RMSE (Root Mean Squared Error)** — 평균제곱오차의 제곱근. 목표변수와 단위가 같아 해석이 쉽다
- **MAPE (Mean Absolute Percentage Error)** — 실제값 대비 오차 비율의 절댓값을 평균해 %로 나타낸 값. 실제값이 0이거나 0에 가까우면 쓸 수 없다
- Q: 실제 10, 20, 30, 예측 12, 18, 33일 때 MAE(소수 셋째 자리) — `2.333`
  - 검산: `(2 + 2 + 3) / 3` = 2.333
- Q: 실제 10, 20, 30, 예측 12, 18, 33일 때 MSE(소수 셋째 자리) — `5.667`
  - 검산: `(2 ** 2 + 2 ** 2 + 3 ** 2) / 3` = 5.667
- Q: 실제 10, 20, 30, 예측 12, 18, 33일 때 RMSE(소수 셋째 자리) — `2.380`
  - 검산: `sqrt((2 ** 2 + 2 ** 2 + 3 ** 2) / 3)` = 2.380
- Q: 실제 10, 20, 30, 예측 12, 18, 33일 때 MAPE(%, 소수 첫째 자리) — `13.3`%
  - 검산: `(2 / 10 + 2 / 20 + 3 / 30) / 3 * 100` = 13.3
- Q: MAE와 RMSE 중 큰 오차(이상값)에 더 민감한 지표 — RMSE

## 분석모형 평가 › 분석모형 진단

- **잔차 (Residual)** — 관측값에서 모형의 예측값을 뺀 값
- Q: 회귀모형 진단에서 확인하는 것 — 잔차의 선형성, 정규성, 등분산성, 독립성과 영향점, 다중공선성
- Q: 잔차를 순서대로 찍었을 때 물결 모양 패턴이 보이면 어긋난 가정 — 독립성 (잔차에 자기상관이 있다)
- **학습 곡선 (Learning Curve)** — 학습 데이터 양이나 반복 횟수에 따라 학습 오차와 검증 오차가 어떻게 변하는지 그린 그래프. 과대적합, 과소적합 진단에 쓴다
- Q: 학습 오차와 검증 오차가 둘 다 높은 채로 붙어 수렴하면 — 과소적합(편향이 큼). 더 복잡한 모형이나 변수 추가가 필요하다
- Q: 학습 오차는 낮은데 검증 오차와의 간격이 크게 벌어져 있으면 — 과대적합(분산이 큼). 데이터 추가, 규제, 더 단순한 모형이 필요하다

## 분석모형 평가 › 교차 검증

- **k-겹 교차 검증 (k-fold Cross Validation)** — 데이터를 k개 묶음으로 나눠 하나씩 돌아가며 검증에 쓰고 나머지로 학습해 k번의 성능을 평균하는 방법
- Q: 데이터 1,000개로 5-겹 교차 검증을 할 때 한 번의 학습에 쓰는 데이터 수 — `800`개
  - 검산: `1000 * (5 - 1) / 5` = 800
- **LOOCV (Leave-One-Out Cross Validation)** — 관측치 하나만 검증에 쓰고 나머지 전부로 학습하는 일을 데이터 수만큼 반복하는 방법. 계산량이 크다
- **LpOCV (Leave-p-Out Cross Validation)** — 관측치 p개를 검증용으로 빼는 모든 조합마다 학습과 검증을 반복하는 방법
- Q: 데이터 5개에서 p=2로 LpOCV를 할 때 반복 횟수 — `10`
  - 검산: `5 * 4 / 2` = 10
- **층화 k-겹 교차 검증 (Stratified k-fold Cross Validation)** — 각 묶음의 클래스 비율이 전체와 같도록 나누는 교차 검증. 불균형 분류에 쓴다
- Q: 시계열 데이터에 맞는 교차 검증 방식 — 시간 순서를 지키며 학습 구간을 늘려 가고 바로 다음 구간으로 검증한다
- Q: 홀드아웃과 비교한 k-겹 교차 검증의 장점과 단점 — 모든 데이터가 한 번씩 검증에 쓰여 성능 추정이 안정적이지만 k번 학습하므로 계산량이 많다

## 분석모형 평가 › 모수 유의성 검정

- Q: 유의수준 0.05에서 p-value가 0.03이면 — 귀무가설을 기각한다
- Q: 1종 오류와 2종 오류 — 1종은 참인 귀무가설을 기각하는 것, 2종은 거짓인 귀무가설을 기각하지 못하는 것
- Q: 모평균 검정에서 모분산을 알 때와 모를 때(소표본) 쓰는 검정 — 알면 Z검정, 모르면 t검정
- Q: 표본평균 52, 가설 모평균 50, 모표준편차 10, 표본 100개일 때 Z 통계량 — `2`
  - 검산: `(52 - 50) / (10 / sqrt(100))` = 2
- Q: 두 집단의 분산이 같은지 보는 검정 — F검정(등분산 검정). 레빈 검정도 쓴다
- Q: 셋 이상 집단의 평균을 비교하는 방법과 통계량 — 분산분석(ANOVA). F통계량은 집단 간 평균제곱을 집단 내 평균제곱으로 나눈 값
- Q: 집단 간 평균제곱 30, 집단 내 평균제곱 5일 때 F 통계량 — `6`
  - 검산: `30 / 5` = 6
- Q: 분산분석에서 귀무가설을 기각한 뒤 어느 집단끼리 다른지 보는 분석 — 사후검정 (투키, 셰페, 본페로니 등)

## 분석모형 평가 › 적합도 검정

- **적합도 검정 (Goodness-of-fit Test)** — 표본 자료가 가정한 이론 분포를 따르는지 확인하는 검정
- Q: 범주형 자료가 기대 비율을 따르는지 보는 적합도 검정과 자유도 — 카이제곱 적합도 검정, 자유도는 범주 수 - 1
- Q: 주사위를 60번 던져 나온 눈의 도수가 5, 10, 10, 10, 10, 15일 때 균등 분포에 대한 카이제곱 통계량 — `5`
  - 검산: `((5 - 10) ** 2 + (15 - 10) ** 2) / 10` = 5
  - 기대도수는 눈마다 10이고 나머지 네 칸은 0을 더한다
- Q: 연속형 자료의 정규성 적합도 검정 예 — 샤피로-윌크, 콜모고로프-스미르노프, 앤더슨-달링
- Q: 로지스틱 회귀모형의 적합도 검정 — 호스머-레메쇼(Hosmer-Lemeshow) 검정. p-value가 크면 잘 맞는다

## 분석모형 개선 › 과대적합 방지

- **과대적합 (Overfitting)** — 학습 데이터의 잡음까지 외워 학습 성능은 높지만 새 데이터에서 성능이 떨어지는 상태
- Q: 과대적합 대처 방법 — 데이터 늘리기(증강), 모형 단순화, L1과 L2 규제, 드롭아웃, 조기 종료
- Q: 과소적합 대처 방법 — 더 복잡한 모형, 변수 추가, 규제 완화, 더 오래 학습
- **L1 규제 (Lasso)** — 손실에 계수 절댓값의 합을 벌점으로 더하는 규제. 일부 계수를 정확히 0으로 만들어 변수 선택 효과가 있다
- **L2 규제 (Ridge)** — 손실에 계수 제곱합을 벌점으로 더하는 규제. 계수를 0 쪽으로 줄이지만 정확히 0으로 만들지는 않는다
- **엘라스틱넷 (Elastic Net)** — 절댓값 벌점과 제곱 벌점을 섞어 쓰는 규제. 상관 높은 변수들을 묶어서 고르는 경향이 있다
- Q: 계수가 (3, -4)일 때 L1 벌점(절댓값 합)과 L2 벌점(제곱합) — L1은 `7`, L2는 `25`
  - 검산: `abs(3) + abs(-4)` = 7
  - 검산: `3 ** 2 + (-4) ** 2` = 25
- Q: 규제 강도(λ)를 키우면 — 계수가 더 작아져 모형이 단순해진다. 지나치면 과소적합된다
- **드롭아웃 (Dropout)** — 학습할 때마다 신경망 뉴런 일부를 무작위로 꺼서 특정 뉴런 조합에 기대지 않게 하는 기법. 예측할 때는 모두 쓴다
- **조기 종료 (Early Stopping)** — 검증 오차가 더 줄지 않고 늘기 시작하면 학습을 멈추는 방법

## 분석모형 개선 › 매개변수 최적화

- Q: 가중치 1.0, 기울기 0.4, 학습률 0.5일 때 경사하강법 한 번 갱신 후 가중치 — `0.8`
  - 검산: `1.0 - 0.5 * 0.4` = 0.8
- **모멘텀 (Momentum)** — 이전 갱신 방향을 관성처럼 누적해 현재 기울기에 더하는 경사하강 변형. 진동을 줄이고 얕은 지역 최솟값을 지나가게 돕는다
- **AdaGrad (Adaptive Gradient)** — 지금까지의 기울기 제곱을 누적해 많이 갱신된 매개변수일수록 학습률을 줄이는 방법. 오래 학습하면 학습률이 거의 0이 된다
- **RMSProp (Root Mean Square Propagation)** — 기울기 제곱의 지수이동평균을 써서 오래된 기울기의 영향을 줄인 AdaGrad 개선판
- **Adam (Adaptive Moment Estimation)** — 기울기의 이동평균(모멘텀)과 기울기 제곱의 이동평균(RMSProp)을 함께 쓰고 초기 편향을 보정하는 옵티마이저
- **그리드 서치 (Grid Search)** — 초매개변수 후보 값의 모든 조합을 하나씩 평가해 가장 좋은 조합을 고르는 방법
- Q: 학습률 후보 3개, 트리 깊이 후보 4개를 5-겹 교차 검증 그리드 서치로 볼 때 모형 학습 횟수 — `60`회
  - 검산: `3 * 4 * 5` = 60
- **랜덤 서치 (Random Search)** — 초매개변수 범위에서 조합을 무작위로 정해진 횟수만큼 뽑아 평가하는 방법. 중요한 초매개변수가 일부일 때 효율적이다
- **베이지안 최적화 (Bayesian Optimization)** — 지금까지의 평가 결과로 성능 함수의 대리 모형을 세우고, 다음에 시도할 조합을 획득 함수로 골라 적은 시도로 최적값을 찾는 방법

## 분석모형 개선 › 분석모형 융합

- Q: 분석모형 융합의 뜻과 방법 예 — 여러 모형의 결과를 결합해 단일 모형보다 성능을 높이는 것. 보팅, 배깅, 부스팅, 스태킹
- Q: 회귀 모형 세 개의 예측 10, 12, 14를 가중치 0.5, 0.3, 0.2로 결합한 값 — `11.4`
  - 검산: `0.5 * 10 + 0.3 * 12 + 0.2 * 14` = 11.4
- Q: 앙상블에 서로 다른 종류의 모형을 섞는 이유 — 모형끼리 오차의 상관이 낮을수록 결합 효과가 크다

## 분석모형 개선 › 최종모형 선정

- Q: 최종 모형을 고를 때 성능 지표 외에 따지는 것 — 해석 가능성, 예측 속도와 자원, 운영 환경 적용성, 유지보수 비용
- Q: 성능이 비슷한 두 모형 중 고르는 원칙 — 더 단순한 모형 (오컴의 면도날)
- Q: 최종 모형 선정에서 테스트 데이터를 쓰는 시점 — 후보를 다 정한 뒤 마지막에 한 번. 여러 번 보며 고르면 테스트 성능이 낙관적으로 나온다
