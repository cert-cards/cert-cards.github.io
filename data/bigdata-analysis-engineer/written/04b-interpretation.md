# 빅데이터 결과 해석 (분석결과 해석 및 활용)

> 4과목 뒷부분. 출제기준(2024.1.1~2026.12.31)의 주요항목 분석결과 해석 및 활용을 다룬다.

## 분석결과 해석 › 분석모형 해석

- **변수 중요도 (Feature Importance)** — 각 입력변수가 모형 예측에 얼마나 기여하는지 나타낸 값
- **순열 중요도 (Permutation Importance)** — 한 변수의 값만 무작위로 섞었을 때 성능이 얼마나 떨어지는지로 그 변수의 기여를 재는 방법. 모형 종류와 상관없이 쓸 수 있다
- **부분 의존도 그림 (Partial Dependence Plot)** — 다른 변수들의 효과를 평균 낸 상태에서 한 변수 값을 바꿀 때 예측이 평균적으로 어떻게 변하는지 그린 그림
- **SHAP (SHapley Additive exPlanations)** — 협력 게임 이론의 섀플리 값으로 예측 한 건을 각 변수의 기여분 합으로 나눠 설명하는 방법
- **LIME (Local Interpretable Model-agnostic Explanations)** — 설명할 예측 주변에서 데이터를 조금씩 바꾼 표본을 만들고 단순한 대리 모형을 학습해 국소적으로 설명하는 방법
- **설명 가능한 인공지능 (XAI, Explainable AI)** — 모형이 왜 그런 예측을 했는지 사람이 이해할 수 있게 보여주는 기술과 방법을 통틀어 이르는 말
- Q: 전역 설명과 국소 설명의 차이 — 전역은 모형 전체의 경향(변수 중요도, 부분 의존도), 국소는 예측 한 건의 이유(LIME, 개별 SHAP 값)
- Q: 두 변수의 상관이 높게 나왔을 때 해석상 주의점 — 상관은 인과가 아니다. 두 변수에 함께 영향을 주는 교란변수가 있을 수 있다

## 분석결과 해석 › 비즈니스 기여도 평가

- **ROI (Return on Investment)** — 투자 비용 대비 얻은 순이익의 비율, (수익-비용)/비용
- Q: 투자 2억 원으로 효과 3억 원을 얻었을 때 ROI (%) — `50`%
  - 검산: `(3 - 2) / 2 * 100` = 50
- **NPV (Net Present Value)** — 미래 현금흐름을 할인율로 현재가치로 바꿔 더한 뒤 초기 투자를 뺀 값. 0보다 크면 투자 가치가 있다
- Q: 초기 투자 100, 1년 뒤 현금흐름 121, 할인율 10%일 때 순현재가치 — `10`
  - 검산: `121 / 1.1 - 100` = 10
- **IRR (Internal Rate of Return)** — 순현재가치를 0으로 만드는 할인율. 요구수익률보다 크면 투자 가치가 있다
- **투자회수기간 (Payback Period)** — 누적 순현금흐름이 초기 투자액과 같아질 때까지 걸리는 기간
- Q: 초기 투자 1,200만 원, 매년 순이익 400만 원일 때 투자회수기간 (년) — `3`년
  - 검산: `1200 / 400` = 3
- **TCO (Total Cost of Ownership)** — 도입비뿐 아니라 운영, 유지보수, 교육 비용까지 시스템 수명 동안 드는 총비용
- Q: 모형이 실제 성과를 높였는지 직접 확인하는 실험 방법 — A/B 테스트 (모형 적용 집단과 기존 방식 집단의 성과 비교)

## 분석결과 시각화 › 시공간 시각화

> 시간 시각화와 공간 시각화를 함께 둔다.

- Q: 시간 시각화에 쓰는 차트 예 — 선 그래프, 시점별 막대 그래프, 계단식 그래프, 영역 차트, 점 그래프
- **선 그래프 (Line Chart)** — 시간 순서대로 찍은 값을 선으로 이어 추세와 변화를 보여주는 그래프
- **계단식 그래프 (Step Chart)** — 값이 다음 변화 시점까지 그대로 유지되다 한 번에 바뀌는 모양으로 그리는 그래프. 금리나 요금처럼 특정 시점에 바뀌는 값에 쓴다
- Q: 공간 시각화에 쓰는 지도 예 — 단계구분도, 카토그램, 버블 플롯맵, 등치선도, 도트맵
- **단계구분도 (Choropleth Map)** — 지역 경계 안을 데이터 값 구간에 따라 색이나 명암으로 칠한 지도
- **카토그램 (Cartogram)** — 지역의 실제 면적 대신 데이터 값에 비례하게 지역 크기를 바꿔 그린 지도
- **버블 플롯맵 (Bubble Plot Map)** — 지도 위 위치에 데이터 값에 비례하는 크기의 원을 그린 지도
- **등치선도 (Isarithmic Map)** — 값이 같은 지점을 선으로 이어 기온, 고도처럼 연속적으로 변하는 값을 나타낸 지도
- **도트맵 (Dot Map)** — 지도 위 해당 위치에 점을 찍어 사건이나 대상의 분포를 나타낸 지도
- Q: 단계구분도의 약점과 이를 보완하는 지도 — 면적이 큰 지역이 값과 상관없이 시선을 끌어 인상을 왜곡한다. 카토그램이 보완한다

## 분석결과 시각화 › 관계 시각화

- **산점도 (Scatter Plot)** — 두 연속형 변수 값을 x, y 좌표의 점으로 찍어 상관 관계를 보여주는 그림
- **산점도 행렬 (Scatter Plot Matrix)** — 여러 변수 쌍의 산점도를 격자로 한꺼번에 배치한 그림
- **버블 차트 (Bubble Chart)** — 두 변수를 좌표로 찍은 점의 크기로 세 번째 변수까지 나타낸 차트
- **히스토그램 (Histogram)** — 연속형 변수를 구간으로 나눠 구간별 빈도를 붙어 있는 막대로 그린 그래프. 분포 모양을 본다
- **상자 그림 (Box Plot)** — 최솟값, 1사분위수, 중위수, 3사분위수, 최댓값과 이상값을 상자와 수염으로 나타낸 그림
- Q: Q1이 20, Q3가 40일 때 1.5×IQR 기준 이상값 상한 경계 — `70`
  - 검산: `40 + 1.5 * (40 - 20)` = 70
- Q: 히스토그램과 막대 그래프의 차이 — 히스토그램은 연속형 변수의 구간 빈도라 막대가 붙어 있고, 막대 그래프는 범주별 값 비교라 막대가 떨어져 있다
- Q: 관계 시각화의 예 — 산점도, 산점도 행렬, 버블 차트, 히스토그램, 네트워크 그래프

## 분석결과 시각화 › 비교 시각화

> 출제기준에는 「분포 시각화」 항목이 없어 막대·누적 막대·파이 차트·트리맵을 여기 두었다. 수험서는 파이 차트, 도넛 차트, 트리맵, 누적 막대(누적 영역) 그래프를 분포 시각화로 묶는 경우가 많으니 「비교 시각화가 아닌 것」을 묻는 문제에 주의한다.

- **히트맵 (Heatmap)** — 행과 열로 놓인 값의 크기를 색의 진하기로 칠해 여러 대상과 변수를 한눈에 비교하는 그림
- **평행 좌표 그래프 (Parallel Coordinates Plot)** — 변수마다 세로축을 나란히 세우고 각 관측치를 축들을 잇는 꺾은선으로 그려 여러 변수를 함께 비교하는 그림
- **체르노프 페이스 (Chernoff Faces)** — 변수 값을 눈, 코, 입 같은 얼굴 요소의 모양과 크기에 대응시켜 관측치 하나를 얼굴 하나로 그린 그림
- **스타 차트 (Star Chart)** — 중심에서 변수 수만큼 뻗은 축에 값을 찍고 이어 다각형으로 비교하는 차트. 레이더 차트, 방사형 차트라고도 한다
- **막대 그래프 (Bar Chart)** — 범주별 값을 막대 길이로 나타내 크기를 비교하는 그래프
- **누적 막대 그래프 (Stacked Bar Chart)** — 막대 하나를 구성 요소 비율대로 나눠 쌓은 그래프. 전체 크기와 구성을 함께 본다
- **파이 차트 (Pie Chart)** — 전체를 원으로 두고 각 범주의 비율을 부채꼴 넓이로 나타낸 차트
- **트리맵 (Treemap)** — 전체 사각형을 계층별로 나누고 범주 값에 비례하는 넓이의 사각형으로 구성 비율을 보여주는 차트
- Q: 비교 시각화의 예 — 히트맵, 평행 좌표 그래프, 체르노프 페이스, 스타 차트, 플로팅 바 차트
- Q: 학생 한 명의 다섯 과목 성적 패턴을 다각형 하나로 보여주기 좋은 그림 — 스타 차트(레이더 차트)
- Q: 막대 그래프의 값 축을 0이 아닌 곳에서 시작하면 생기는 문제 — 차이가 실제보다 과장되어 보인다

## 분석결과 시각화 › 인포그래픽

- **인포그래픽 (Infographic)** — 정보(information)와 그래픽(graphic)을 합친 말로, 복잡한 데이터나 지식을 그림, 도표, 아이콘으로 압축해 빠르게 이해하게 만든 시각물
- Q: 인포그래픽 유형 예 — 지도형, 도표형, 타임라인형, 스토리텔링형, 비교분석형, 만화형
- Q: 탐색용 데이터 시각화와 비교한 인포그래픽의 목적 — 탐색보다 전달이 목적이라 메시지를 좁히고 디자인 요소로 이야기를 만든다
- Q: 시각화 과정의 세 단계 — 구조화(목표와 데이터 정리, 스토리 구성), 시각화(차트와 도구를 골라 그리기), 시각표현(그래픽 요소를 다듬어 완성)

## 분석결과 활용 › 분석모형 전개

- **분석모형 전개 (Model Deployment)** — 완성한 모형을 실제 운영 시스템에 올려 업무에서 예측 결과를 쓸 수 있게 하는 단계
- Q: 배치 예측과 실시간 예측의 차이 — 배치는 정해진 주기로 많은 데이터를 한꺼번에 예측하고, 실시간은 요청이 올 때마다 바로 예측해 응답한다
- **PMML (Predictive Model Markup Language)** — 학습한 예측 모형을 XML 기반 표준 형식으로 기술해 다른 도구나 시스템에서 쓸 수 있게 하는 언어
- **MLOps (Machine Learning Operations)** — 모형 개발, 배포, 모니터링, 재학습을 자동화해 끊김 없이 관리하는 운영 체계. DevOps를 머신러닝에 적용한 것이다
- **카나리 배포 (Canary Deployment)** — 새 모형을 일부 트래픽에만 먼저 적용해 문제가 없는지 확인한 뒤 범위를 넓히는 배포 방식
- Q: 운영 환경에서 학습 때와 같은 전처리를 해야 하는 이유 — 입력 처리가 다르면 학습 때와 다른 분포가 들어가 성능이 떨어진다(학습-서빙 불일치)

## 분석결과 활용 › 분석결과 활용 시나리오 개발

- Q: 활용 시나리오 개발의 출발점 — 분석 결과를 누가, 어떤 업무 의사결정에서, 어떻게 쓸지 정하는 것
- Q: 활용 시나리오를 만들 때 정하는 것 — 사용자와 업무 프로세스, 결과 제공 방식(대시보드, 알림, API), 기대 효과를 잴 지표
- **대시보드 (Dashboard)** — 핵심 지표와 분석 결과를 한 화면에 모아 바로 확인하게 만든 화면
- **핵심성과지표 (KPI, Key Performance Indicator)** — 목표를 얼마나 달성했는지 재려고 미리 정해 둔 주요 성과 지표
- Q: 분석 과제의 성과를 관리할 때 쓰는 두 종류 지표 — 정량 지표(매출 증가, 비용 절감, 정확도)와 정성 지표(업무 만족도, 의사결정 속도)

## 분석결과 활용 › 분석모형 모니터링

- **데이터 드리프트 (Data Drift)** — 운영 중 들어오는 입력 데이터의 분포가 학습 데이터 분포와 달라지는 현상
- **개념 드리프트 (Concept Drift)** — 입력과 목표변수 사이의 관계 자체가 시간이 지나며 바뀌는 현상. 같은 입력이어도 정답이 달라진다
- **PSI (Population Stability Index)** — 학습 시점과 운영 시점의 변수나 점수 분포를 구간별로 비교해 분포가 얼마나 바뀌었는지 나타낸 지표. 0.1 미만은 안정, 0.25 이상은 큰 변화로 흔히 본다
- Q: 기준 비율 0.2, 현재 비율 0.3인 구간의 PSI 기여분(소수 셋째 자리) — `0.041`
  - 검산: `(0.3 - 0.2) * log(0.3 / 0.2)` = 0.041
- Q: 모형 모니터링에서 보는 것 — 예측 성능 지표, 입력 데이터 분포, 응답 시간과 처리량, 오류율, 자원 사용량
- Q: 정답이 늦게 확정되는 업무(대출 연체 예측 등)에서 성능 대신 먼저 감시하는 것 — 입력 데이터와 예측 점수의 분포 변화
- **챔피언-챌린저 (Champion-Challenger)** — 운영 중인 모형과 새 후보 모형을 같은 조건에서 비교해 더 나은 쪽으로 교체하는 방식

## 분석결과 활용 › 분석모형 리모델링

- **리모델링 (Remodeling)** — 성능이 떨어지거나 환경이 바뀐 모형을 데이터, 변수, 알고리즘 수준에서 다시 손보는 작업
- Q: 재학습과 리모델링의 차이 — 재학습은 구조는 그대로 두고 최신 데이터로 다시 학습하는 것, 리모델링은 변수와 알고리즘까지 바꿀 수 있는 개선
- Q: 리모델링 시점을 정하는 두 방식 — 분기, 반기처럼 정해진 주기로 하거나 성능 저하나 드리프트가 감지될 때 한다
- Q: 리모델링한 모형이 기존보다 나은지 판단하는 방법 — 같은 최신 평가 데이터로 기존 모형과 비교하고, 가능하면 A/B 테스트나 챔피언-챌린저로 검증한다
