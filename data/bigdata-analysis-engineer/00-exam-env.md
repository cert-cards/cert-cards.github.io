# 시험 환경과 답안 제출

> 한국데이터산업진흥원의 「빅데이터분석기사 실기 체험 환경 가이드」(2025-06-05판)와 공식 체험환경(dataq.goorm.io, 제12회 버전)에서 확인한 내용이다. 패키지와 세부 운영은 회차마다 달라질 수 있으니 시험 전에 체험환경과 데이터자격검정 공지사항을 한 번 더 본다.

## 시험 환경

- Q: 실기 시험이 치러지는 환경 — 클라우드 기반 CBT, 크롬 브라우저
- Q: R과 Python 중 언어를 고르는 단위 — 문제마다 따로 고른다
- Q: 코드 한 번 실행에 주어지는 시간 — 1분. 넘으면 실행이 강제로 취소된다
  - 무거운 모델이나 넓은 하이퍼파라미터 탐색은 1분 안에 끝나는지 먼저 확인한다
- Q: 코드를 한 줄씩 골라 실행할 수 있나 — 없다. 실행하면 작성한 코드 전체가 처음부터 돈다
- Q: 시험 화면에서 제공되지 않는 기능 세 가지 — 그래프, 단축키, 자동완성
- Q: 시험 중 pip로 패키지를 더 설치할 수 있나 — 없다. 제공된 패키지만 쓴다
- Q: 함수 이름이나 인자가 기억나지 않을 때 시험장에서 쓸 수 있는 것 — `help()`, `dir()` (R은 `?`)
- Q: 설치된 패키지와 버전을 확인하는 방법 — `pkg_resources.working_set`을 돌며 이름과 버전을 출력하는 코드를 실행한다
  - 체험환경 첫 화면의 기본 코드가 바로 이 코드다
- Q: 제12회 체험환경의 파이썬 패키지 수 — 63개
- Q: 제12회 체험환경의 pandas · numpy · scikit-learn 버전 — 2.2.2 · 1.26.4 · 1.5.2
  - scipy 1.14.1, statsmodels 0.14.1도 있다. 회차마다 바뀔 수 있다
- Q: 제12회 체험환경에 있는 부스팅 라이브러리 — lightgbm 4.5.0, xgboost 2.1.2
- Q: 제12회 체험환경에 있는 통계 검정용 패키지 중 scipy·statsmodels 말고 하나 — pingouin 0.5.5
- Q: 실행 뒤 「실행에 실패했습니다」 안내가 떴는데 결과는 정상으로 출력됐다면 — Warning 때문이면 무시해도 된다. Error면 원인을 찾아 고친다
  - 가이드가 Warning 메시지는 실행과 결과에 영향이 없다고 안내한다
- Q: 실제 시험에서 「저장」 버튼의 쓰임 — 작성 중인 코드를 저장한다. 풀면서 주기적으로 눌러 두라고 권장된다
  - 체험환경에서는 저장이 동작하지 않고, 문제를 옮기면 코드가 지워진다
- Q: 「초기화」 버튼을 누르면 — 작성한 코드가 모두 지워지고 기본 코드로 돌아간다
- Q: 「테스트 케이스 추가」와 「테스트」 버튼 — 본 시험에서는 쓰지 않는다
- Q: 메모장을 쓸 수 있는 화면 — 문제 풀이 화면. 답안 제출 화면에는 없다
  - 입력 후 1초 안에 자동 저장되고, 「문제탭 자동 이동」을 켜면 메모 탭이 문제 번호를 따라간다

## 제1·3유형 답안 제출

- Q: 제1유형과 제3유형의 답을 내는 곳 — 문제 풀이 화면과 분리된 별도의 답안 제출 화면
  - 풀이 화면에는 「제출」 버튼이 없다. 코드로 값을 구한 뒤 제출 화면으로 옮겨 입력한다
- Q: 소문항이 ①②③으로 나뉜 문제의 답 입력 순서 — 소문항 순서대로 각 칸에 하나씩
- Q: 지시된 제출 형식과 다르게 입력하면 — 입력 형식 오류 메시지가 뜬다
- Q: 「반올림하여 소수 둘째 자리까지」인 칸에 `0.011`을 넣으면 — 형식 오류. 소수 셋째 자리까지 들어갔다
- Q: 답을 여러 번 제출하면 채점되는 것 — 마지막으로 제출한 답안
- Q: 제출 형식이 「버림하여 정수」일 때 출력 결과는?
  ```text
  import math
  x = 5127.86
  print(int(x), math.floor(x), round(x))
  ```
  - 답: `5127 5127 5128`
  - 양수에서는 `int`와 `math.floor`가 같다. `round`는 반올림이라 버림 지시에 쓰면 틀린다
- Q: 출력 결과는?
  ```text
  import math
  x = -2.4
  print(int(x), math.floor(x))
  ```
  - 답: `-2 -3`
  - 음수에서는 `int`가 0 쪽으로, `math.floor`가 더 작은 쪽으로 자른다. 음수 값을 버림하라는 지시가 나오면 어느 쪽인지 문제를 다시 읽는다
- Q: 제출 형식이 「반올림하여 소수 셋째 자리까지」일 때 출력 결과는?
  ```text
  x = 0.0123456
  print(round(x, 3), f'{x:.3f}')
  ```
  - 답: `0.012 0.012`
- Q: 출력 결과는?
  ```text
  x = 0.1
  print(round(x, 3), f'{x:.3f}')
  ```
  - 답: `0.1 0.100`
  - `round`는 뒤쪽 0을 찍지 않는다. 칸에 옮길 때 자릿수를 눈으로 다시 확인한다

## 제2유형 답안 제출

- Q: 제2유형에서 제출하는 것 — 예측 결과 CSV 파일을 만드는 코드 (풀이 화면의 「제출」 버튼)
- Q: 제2유형을 여러 번 제출하면 채점되는 것 — 마지막으로 제출한 코드가 만든 CSV 파일
- Q: 체험환경 제2유형 예시의 CSV 파일명과 예측 칼럼명 — `result.csv`, `pred`
  - 실제 시험은 문제에 적힌 이름을 그대로 쓴다
- Q: 답안 CSV에 들어갈 칼럼 수 — 예측 결과 칼럼 1개만
  - ID나 다른 칼럼을 함께 넣지 않는다
- Q: 답안 CSV를 저장할 때 판다스가 자동으로 붙이는 것 중 빼야 하는 것 — index 칼럼 (`index=False`)
- Q: `to_csv('output/result.csv')`처럼 폴더를 붙여 저장해도 되나 — 안 된다. 디렉토리를 지정하지 않고 파일명만 쓴다
- Q: 예측 결과 행 수가 맞아야 하는 대상 — 평가용(test) 데이터의 행 수
  - 체험 예시는 평가용 데이터 2,482개와 같아야 한다고 명시했다
- Q: 체험환경에서 학습·평가 데이터를 읽는 기본 경로 — `data/` 폴더 아래 (`pd.read_csv('data/customer_train.csv')`)
- Q: 체험환경 제2유형 예시 문제의 평가지표 — RMSE (총구매액 예측, 회귀)
  - 평가지표는 문제마다 다르다. 분류 문제면 ROC-AUC나 F1 등이 지시된다
- Q: 빈칸 ①②③에 들어갈 것은?
  ```text
  import pandas as pd
  pred = model.predict(X_test)
  pd.DataFrame({'①': pred}).to_csv('②', index=③)
  ```
  - 답: ① `pred` ② `result.csv` ③ `False`
  - 이름은 체험 예시 기준. 시험에서는 문제의 지시를 따른다
- Q: 출력 결과는?
  ```text
  import pandas as pd
  sub = pd.DataFrame({'pred': [1.5, 2.0]})
  print(sub.to_csv(index=False).splitlines())
  print(sub.to_csv().splitlines())
  ```
  - 답:
    ```text
    ['pred', '1.5', '2.0']
    [',pred', '0,1.5', '1,2.0']
    ```
  - `index=False`를 빼면 이름 없는 index 칼럼이 앞에 붙어 칼럼이 2개가 된다
- Q: 제출 전에 CSV를 다시 읽어 확인할 두 가지 — 칼럼 이름과 개수, 행 수
  - `pd.read_csv('result.csv')`로 읽어 `.columns`와 `len()`을 찍어 본다
